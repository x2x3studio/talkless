Local-first is a starting point, not a blanket promise that every feature is offline. Here is how the app and this website handle data.

Apple Silicon · macOS 26+ · Source available

Speech and model downloads

Local Qwen processes audio on your Mac. Apple recognition runs on-device after required assets are available. Downloading models contacts the model source you choose; Talkless does not host the weights. Optional cloud recognition uploads the full recording and dictionary hints to your speech provider.

Optional AI requests

Polishing sends the transcript, dictionary hints and editing instructions. App-aware tone can include the foreground app and its writing context. Your additional instructions and output language are included when set. Voice editing sends the selection and spoken instruction; translation sends the selection and language instructions.

Opening AI settings does not send your text. Fetch Models and Test Connection are explicit network actions; a connection test uses a fixed sample, not your dictation. Provider pricing, processing and retention policies apply. Talkless cannot guarantee a provider’s privacy practices.

History and credentials

Preferences, dictionary terms and dictionary fixes use macOS UserDefaults. AI service keys and the cloud speech-recognition key use macOS Keychain. A speech key that older versions stored in plaintext UserDefaults moves to Keychain on first launch.

Models, text history, text-free daily totals and diagnostics live in your Mac’s Library/Application Support/Talkless folder. History contains text, not audio, and holds up to 500 results. Delete saved text in History; clear daily activity separately. Daily totals are retained for 400 calendar days.

Diagnostics you choose to share

Event logs are bounded to 15 MB and exclude audio, transcripts, API keys and prompts. Export diagnostics creates a local ZIP; it does not upload it. Optional macOS crash reports can contain personal information and file paths. Inspect an export before sharing it.

This website and distribution

The app does not collect telemetry. This website has no analytics, tracking scripts, remote fonts or microphone access. Its host may keep standard request logs. The demo uses sample text in your browser. The language preference is stored locally when available.

Download buttons use this site’s /download address, then redirect to the published GitHub release asset. GitHub handles that download under its own policies. Talkless is source available: you can inspect the repository from the single GitHub link in the header. This wording does not grant a software license.
