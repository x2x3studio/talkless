Build 1793441430 · 2026-10-31

What changed

  • Dictionary review merges suggestions without regard to case, skips capitalization-only changes, and avoids recommending existing terms again while preserving saved spellings.
  • Removed the explanatory language-change hint from the translation panel.
  • Translation shortcut capture now asks for a key combination, while dictation capture still asks for a single key.
  • The completion checkmark now stays for 50 milliseconds after insertion instead of two seconds.

Install or update

The download is a Developer ID signed and notarized disk image for Apple Silicon and macOS 26+. Open it and drag Talkless into Applications. If you already use Talkless, Check for Updates is available from its menu bar menu. You choose when to download and install.

A note about betas

Beta builds can have rough edges. Update checks follow your selected Stable or Beta channel. Switching back to Stable does not downgrade an installed beta. Speech models are downloaded separately and are not bundled with app updates.
